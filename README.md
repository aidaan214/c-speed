=# C Speed

C Speed is an early programming language project aimed at high-performance data analysis, AI applications, rocket and aerospace calculations, scientific computing, and graphics-heavy games.

Version 2.00 expands the interpreter with source imports, functions, booleans, comparisons, conditionals, loops, and mathematical expressions.

Visit the [official C Speed website](https://cspeed.vercel.app/) to learn more.

## Beginner's Guide

Open the [beginner's guide](./LEARN.md) for runnable syntax examples and an explanation of what the current prototype supports and what is still planned.

## C Speed IDLE Editor

C Speed IDLE is a small Windows code editor for writing `.csp` programs.

It includes:

- Syntax coloring
- Line numbers
- File open and save support
- A Run button
- F5 keyboard shortcut support
- C Speed program output windows
